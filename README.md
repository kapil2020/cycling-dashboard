# Global Cycling & Motorcycle Mode Share Dashboard

A modern, interactive dashboard for visualizing cycling and motorcycle mode share data across global cities.

## Features

- 🌍 Interactive world map visualization
- 📊 Multiple chart types (bar, pie, scatter, maps)
- 🌙 Light/Dark mode toggle
- 🔍 Advanced filtering and search
- 📱 Fully responsive design
- ⚡ Fast and lightweight

## Deployment

This dashboard is designed for easy deployment on GitHub Pages.

### Automatic Deployment

1. Fork this repository
2. Go to Settings → Pages
3. Select "GitHub Actions" as source
4. Push to main branch to trigger deployment

### Manual Deployment

1. Clone the repository
2. Push to your GitHub repository
3. Enable GitHub Pages in repository settings

## Data Source

The dashboard uses cycling and motorcycle mode share data from cities worldwide, including:
- Training data used for prediction models
- Demo predictions for demonstration cities
- Collated data from various sources

## Technologies Used

- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5 for UI components
- Plotly.js for interactive charts
- Font Awesome for icons
- Papa Parse for CSV processing
